Install

Get it into your DAW.

There's no installer. It's a folder you copy, so it only takes a couple of minutes. You'll need Windows 10 or 11, 64-bit, and a 64-bit DAW that loads VST3.

Install

  1. Close your DAW.
  2. Right-click the downloaded zip and choose Properties. If there's an Unblock box at the bottom, tick it and click OK. Do this before you extract it.
  3. Extract the zip.
  4. Copy the whole .vst3 folder (Spanda.vst3, Akasa.vst3 or Tula.vst3) into C:\Program Files\Common Files\VST3. Windows will ask for administrator permission. Copy the folder as it is, not just the files inside it.
  5. Open your DAW and rescan plug-ins if it doesn't find the plug-in by itself. Look under the manufacturer Audio Citra.

Trial and licence

The 14-day trial starts the first time the plug-in runs, with nothing locked. After that it passes your audio through unprocessed until you add a licence. Your settings stay as they were.

After you buy, the licence comes by e-mail. Add it in any one of these ways:

  • If you clicked Buy inside the plug-in, click Fetch licence there.
  • Import the licence from the plug-in's Support panel, or paste the whole text into the Licence page.
  • Save it as a file named for the plug-in, like spanda.licence, in C:\Audio Citra\Licences.

An Everything licence only has to go in once. Import it in any plug-in and it unlocks all of them.

Update

The plug-ins can check for updates themselves, and they ask you first before checking automatically. To update by hand, close your DAW, delete the old .vst3 folder and copy the new one in. Your sessions and presets are kept. See what's changed.

Uninstall

Delete the plug-in's .vst3 folder from C:\Program Files\Common Files\VST3.
